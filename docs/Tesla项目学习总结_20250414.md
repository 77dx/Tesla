## 项目概述
Tesla是一个基于Django + Vue3的自动化测试平台，提供完整的测试管理解决方案，包括接口测试用例管理、测试套件编排、异步执行、结果追踪与报告查看等功能。

## 一、项目架构分析

### 1.1 技术栈
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 后端框架 | Django 4.2 + Django REST Framework | RESTful API设计 |
| 前端框架 | Vue 3 (Composition API) + Vite | 现代前端架构 |

| API文档 | drf-spectacular | 自动生成OpenAPI文档 |
| 容器化 | Docker Compose | 一键部署 |

## 二、核心模块分析

### 2.1 认证与权限系统（account + system模块）
- **用户认证**：基于JWT的身份验证，支持token刷新和黑名单机制
- **权限管理**：基于权限码的细粒度访问控制
- **角色系统**：角色与权限多对多关系，管理员自动放行机制
- **Profile扩展**：扩展Django User模型，支持头像、昵称等个人信息

### 2.2 多租户产品线系统（product_line模块）
- **核心设计**：产品线作为租户隔离单位，支持多产品线并行
- **成员管理**：用户通过ProductLineMember加入产品线，支持不同角色
- **资产共享**：接口、用例、套件在相同产品线内共享
- **权限隔离**：产品线级别的权限控制，确保数据安全

### 2.3 项目管理体系（project模块）
- **三级结构**：项目 → 迭代 → 需求，层级清晰
- **状态管理**：规划中、进行中、测试中、已完成、已归档等状态
- **引用关系**：项目和迭代可引用用例和套件，支持灵活的执行范围
- **优先级管理**：普通、重要、紧急三个优先级

### 2.4 测试用例管理（case_api模块）
- **接口定义**：Endpoint模型定义HTTP接口（URL、方法、参数等）
- **测试用例**：Case模型基于接口创建测试用例，支持参数化配置
- **依赖管理**：DAG（有向无环图）驱动执行，requires/provides字段
- **脚本支持**：pre_script/post_script支持前后置脚本
- **变量提取**：支持从响应中按规则提取变量，支持${varName}占位符替换

### 2.5 测试套件管理（suite模块）
- **套件编排**：将多个用例编排成测试套件，支持顺序执行
- **环境配置**：服务注册、环境变量、全局配置
- **Mock支持**：支持Mock规则和环境变量
- **执行引擎**：SuiteRunner顺序执行引擎，支持依赖解析

### 2.6 自动化测试（automation模块）
- **Playwright集成**：支持UI自动化测试
- **Git仓库管理**：支持测试代码版本管理
- **自定义命令**：支持自定义测试执行命令
- **报告生成**：自动生成测试报告

## 三、测试执行引擎架构

### 3.1 核心组件
1. **ContextStore**：上下文变量存储，支持Redis和内存两种后端
2. **VarResolver**：占位符替换器，支持${varName}和${func()}格式
3. **Extractor**：从响应中按规则提取变量，支持JSONPath、正则表达式等
4. **Assertor**：断言执行器，支持新旧格式兼容
5. **CaseRunner**：单条用例执行器，集成HTTP请求、变量提取、断言验证

### 3.2 执行流程
```python
# 伪代码示意
1. 解析用例依赖，构建DAG
2. 按依赖顺序执行用例
3. 对每条用例：
   a. 解析前置脚本，执行前置操作
   b. 替换变量占位符（${varName}）
   c. 发送HTTP请求
   d. 从响应中提取变量，存入上下文
   e. 执行断言验证
   f. 执行后置脚本
4. 汇总执行结果，生成报告
```

## 四、前端架构分析

- **项目相关页面**：项目管理、迭代管理
- **测试相关页面**：接口管理、用例管理、套件管理
- **系统管理页面**：用户管理、权限管理、产品线管理

### 4.3 权限控制

- **动态菜单**：根据用户权限动态渲染菜单项

```bash

redis-server
```
