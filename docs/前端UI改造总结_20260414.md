## 一、设计系统重构

### 1.1 新建文件
- `frontend/src/assets/tesla-design-system.css` — 全新 Tesla 品牌设计系统
- `frontend/src/assets/tesla-common.css` — 通用组件样式库

### 1.2 色彩体系

| 颜色类型 | 色值 | 使用场景 |
|---------|------|---------|
| 主色（Primary） | `#3B82F6` | 按钮、链接、聚焦环 |
| 成功（Success） | `#10B981` | 通过/成功状态 |
| 警告（Warning） | `#F59E0B` | 警告/等待状态 |
| 错误（Error） | `#EF4444` | 失败/错误状态 |
| 页面背景 | `#F9FAFB` | 浅灰底色，干净 |
| 卡片背景 | `#FFFFFF` | 纯白容器 |

### 1.3 字体排印

| Token | 值 | 用途 |
|-------|-----|------|
| `--font-sans` | Inter | 全局字体 |
| `--text-xs` | 11px | 微型标签 |
| `--text-sm` | 13px | 辅助文字 |
| `--text-base` | 14px | 正文基准 |
| `--text-lg` | 18px | 小标题 |
| `--text-2xl` | 24px | 页面标题 |
| `--text-3xl` | 30px | Hero标题 |

### 1.4 间距与圆角

- **间距基准**：8px 系统（space-3=4px, space-5=8px, space-6=12px...）
- **圆角**：sm=4px, md=6px, lg=8px, xl=12px, full=9999px
- **阴影**：shadow-sm → shadow-xl 五级体系

## 二、LayoutView 全新设计

### 核心改进
1. **侧边栏**
   - 宽度 240px → 折叠 64px
   - 分组导航（工作台、测试资产、执行调度、配置管理、系统）

3. **交互细节**
   - 侧边栏状态持久化（localStorage）
   - 全屏切换支持
   - 优雅的淡入淡出过渡动画

## 四、ProjectView 重新设计

### 核心组件
1. **统计卡片行**：4个指标（总项目、活跃、成员、今日执行）
2. **筛选栏**：搜索框 + 状态筛选 + 负责人筛选 + 清除按钮
3. **表格卡片**
   - 工具栏：记录数 + 批量删除（选中时显示）
   - 项目列表：带头像的项目名称行、状态标签、负责人头像、操作图标
   - 分页器：右侧对齐
4. **空状态**：大图标 + 说明 + 创建按钮
5. **模态框**：干净表单 + 实时验证 + 底部双按钮

### 特色细节
- 项目名称单元格带头像（首字母 + 颜色）
- 状态标签带小圆点
- 负责人头像（圆形 + 姓名首字母 + 哈希颜色）
- 操作按钮 Tooltip + hover 变色

`frontend/src/views/ProjectView.vue`

## 七、后续建议

1. **其他列表页改造**：SuiteView、CaseView、EndpointView、ResultView 可参考 `tesla-common.css` 中的通用类
2. **表单页统一**：SuiteFormView、CaseFormView 等表单页可复用 ProjectView 中的表单模式
3. **暗色模式**：可在 `tesla-design-system.css` 中添加 `@media (prefers-color-scheme: dark)` 块
4. **Loading 状态**：统一 Skeleton 样式
5. **图标系统**：考虑将 Ant Design 图标替换为自定义 SVG，更符合 Tesla 品牌调性
