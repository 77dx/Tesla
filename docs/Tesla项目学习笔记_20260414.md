## 一、项目概览

**Tesla** 是一个基于 **Django + Vue3** 的自动化测试管理平台，覆盖接口用例管理、测试套件编排、异步执行、结果追踪与报告查看。

### 核心特性
- 多租户架构（基于产品线）
- 异步执行（Celery + Redis）
- 接口 / 用例 / 套件三层管理
- 项目 + 迭代二级执行范围
- 执行快照追溯
- CSV/Excel 异步导入用例

## 四、前端架构

### 4.1 路由结构

入口：`/login` → 登录后重定向 `/dashboard`

主布局：`LayoutView.vue`（侧边栏 + 顶部栏 + 内容区）

主要页面路由：

| 路由 | 组件 | 功能 |
|------|------|------|
| `/dashboard` | DashboardView | 首页仪表盘 |
| `/projects` | ProjectView | 项目管理 |
| `/sprints` | SprintView | 迭代管理 |
| `/sprints/:id` | SprintDetailView | 迭代详情 |
| `/endpoints` | EndpointView | 接口管理 |
| `/endpoints/:id` | EndpointDetailView | 接口详情 |
| `/cases` | CaseView | 接口用例列表 |
| `/cases/:id` | CaseDetailView | 用例详情 |
| `/ui-cases` | UICaseView | UI 用例列表 |
| `/suites` | SuiteView | 套件列表 |
| `/suites/:id` | SuiteDetailView | 套件详情 |
| `/results` | ResultView | 执行结果 |
| `/results/:id` | ResultDetailView | 结果详情 |
| `/environments` | EnvironmentView | 环境管理 |
| `/product-lines` | ProductLineView | 产品线管理 |
| `/automation` | AutomationView | 脚本调度与数据集 |
| `/account` | AccountView | 个人信息 |
| `/system` | SystemView | 系统管理 |

## 五、后端架构

### 5.1 主模块

| 模块 | 功能 |
|------|------|
| `account` | 用户登录、JWT Token、用户信息 |
| `product_line` | 产品线管理、多租户隔离 |
| `project` | 项目 CRUD、迭代管理 |
| `case_api` | 接口定义、用例管理 |
| `suite` | 套件编排、执行调度、结果管理 |
| `ui_case_runs` | UI 用例执行 |
| `automation` | 外部脚本调度、数据集管理 |
| `system` | 系统配置 |
| `reports` | Allure 报告存储 |

### 5.2 核心 API 路由

```
POST /api/account/login/          # 登录
POST /api/account/logout/         # 登出

GET  /api/project/product-line/    # 产品线列表
POST /api/project/project/        # 创建项目
GET  /api/project/project/        # 项目列表
POST /api/project/project/{id}/run/  # 项目级执行

GET  /api/case/case/              # 用例列表
POST /api/case/case/              # 创建用例
GET  /api/case/endpoint/          # 接口列表

GET  /api/suite/suite/            # 套件列表
POST /api/suite/suite/            # 创建套件
POST /api/suite/suite/{id}/run/   # 执行套件
GET  /api/suite/run-result/       # 执行结果

POST /api/suite/import-job/       # 导入任务
POST /api/suite/import-job/{id}/start/  # 启动导入
```

### 5.3 异步任务

- **Celery Worker** - 处理测试执行、导入任务
- **django-q** - 定时调度（定时套件执行）

## 六、启动方式

```bash
# 1. Redis
redis-server

# 2. 后端
cd backend && python manage.py runserver

# 3. Celery Worker
cd backend && celery -A Tesla worker -l info

# 4. 定时调度
cd backend && python manage.py run_suite_scheduler

# 5. 前端
cd frontend && npm run dev
```

访问：
- 前端：http://localhost:5173
- 后端 API：http://localhost:8000/api
- Swagger：http://localhost:8000/api/schema/swagger/
